# Portfolio Syahrul Juharsyah

Portofolio ini bisa digunakan untuk umum silahkan kalian coba.

## Cara edit
1. Buka `index.html` untuk mengubah nama, deskripsi, kontak, dan link sosial.
2. Buka `script.js` untuk mengubah daftar skill dan project.
3. Ganti `assets/Photoroom-20260727_205811.png` dengan foto kamu (misalnya `profile.jpg`) lalu ubah `src` di `index.html`.
4. Ganti gambar project di folder `assets/`.
5. Upload semua file ke repository `USERNAME.github.io`.
6. Aktifkan GitHub Pages dari Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Catatan
- `assets/CV.pdf` belum disertakan. Masukkan file CV kamu dengan nama tersebut, atau ubah link CV di `index.html`.
- Ganti semua `USERNAME` dengan username GitHub kamu.

Selamat Mencoba 🙂
